# Changelog

## 2.0.0 — 2026-11-10

- Added Positive and Literal Negation perspectives alongside the seven existing styles; each mode has its own AI instructions, including grammar and tense guidance.
- Added offline daily motivation with a separate, configurable 8:00 AM local reminder; kept the current-reality notification independent.
- Removed developer connection details from Settings and replaced technical errors with useful end-user messages.
- Added personal preview invitations, Android secure storage, independently revocable server access, per-tester daily limits, global limits and persistent quota accounting.
- Persisted selected perspective and current-notification preference; protected valid history from damaged records and bounded storage to the latest 500 entries.
- Improved onboarding, large-text layouts, sharing, microphone completion, duplicate-submission handling and failed regeneration recovery.
- Added separate signed Android Preview distribution, explicit release signing, HTTPS-only release configuration, deployment container, automated checks and tester documentation.
- Hosting remains deferred. The packaged offline preview does not generate AI perspectives until a connected update is built.
